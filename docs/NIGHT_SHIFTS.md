# 야간 근무·누락 기록·월 시급

## 자정을 넘는 출퇴근

22시 출근, 다음 날 04시 퇴근은 한 근무 6시간으로 저장한다. 근무 중 상태는 날짜가 아닌 미종료 기록으로 판단하므로 00시에 초기화하지 않는다. 새로고침·다음 날 명단 조회에도 같은 기록을 사용한다. 날짜별·주별·월별 조회에서는 출근일 2시간, 퇴근일 4시간으로 나눈다. 실제 휴게시간이 있으면 각 구간에 비례해서 공제한다.

한국 시각을 기준으로 각 날짜의 시급·하루 예외·휴일 배율을 적용한다. 일요일~월요일이나 월말~다음 달도 같은 원칙으로 나눈다. 24시간이 넘는 미종료 기록은 확인 필요로 표시하며 자정에 자동 종료하거나 삭제하지 않는다. 관리자가 실제 날짜·시간을 확인해 정정한다.

## 출퇴근을 누락했을 때

- 둘 다 누락: **근무기록 → 출퇴근 직접 입력**에서 직원과 출근·퇴근 날짜/시간, 실제 휴게, 사유를 입력한다.
- 퇴근만 누락: 기존 **근무 중** 기록의 **정정**에서 실제 퇴근 날짜/시간을 입력한다. 같은 구간을 새 기록으로 중복 등록하지 않는다.
- 새벽 퇴근: 퇴근 날짜도 다음 날로 선택한다. 같은 날 22시~04시로 입력했으면 **퇴근을 다음 날로 변경** 버튼을 제공한다. 저장 전 구간과 다음 날 여부를 표시한다.

시간 역전, 미래 시각, 24시간 초과, 다른 기록과 겹침, 전체 근무보다 긴 휴게는 거부한다. 진행 중인 기록은 퇴근을 비울 수 있다. 두 관리자가 동시에 정정하면 revision이 다른 저장을 거부한다. 메모·휴게만 바꾸면 원래 서버 시각의 초·밀리초를 그대로 보존한다. 모든 등록·정정에는 사유와 관리자 이력이 남는다.

승인 대기 출퇴근이 별도로 남아 있다면 수동 입력 기록과 비교해 처리한다. 승인 대기는 실제 근무에 포함되지 않으며 이미 보완한 구간을 다시 승인하면 중복 검사로 차단한다.

## 월 시급과 하루 예외

**월 시급**은 선택 월 1일부터 다음 저장된 시급 변경 전까지 유지한다. 해당 월의 기존 날짜별 기본 시급 변경이 있으면 화면에 통합 대상을 알리고 월 시급 하나로 정리한다. 다른 달 이력과 하루 시급은 수정하지 않는다. 저장 시 해당 월 이력 전체를 다시 비교해 오래된 관리자 화면의 덮어쓰기를 거부한다. 과거 확정 정산본은 보존하고 현재 금액과의 차액을 계산한다.

**하루 시급**은 별도 화면에서 관리하며 선택한 날짜에만 우선 적용한다. 자정이 지나면 다음 날 기본 시급을 사용한다. 월 시급을 수정해도 하루 예외는 유지한다. 예외를 해제해야 월 시급을 사용한다. 이미 저장된 다른 달의 월중 변경은 과거 이력으로 표시하며 그 달을 수정할 때만 통합한다.

기존에 열려 있는 이전 앱과 과거 데이터 호환을 위해 날짜 기준 API는 유지한다. 새 관리자 화면은 월 기준 API를 사용한다. 기존 시급 이력을 배포만으로 일괄 변경하지 않는다.

## 태블릿 대기와 관리자 로그인

출퇴근 화면은 시간 제한 없이 유지하며 앱이 화면 전원을 끄지 않는다. 실제 화면 꺼짐·충전·밝기는 기기 설정으로 관리한다. 관리자 로그인에 있던 별도 2분 제한은 제거하고 PC와 동일한 30분 미사용·최대 12시간 제한을 적용한다. 공용 태블릿에서 관리자 화면을 떠날 때 로그아웃하는 기능은 유지한다.

## 테스트 데이터 정리

운영자 전용 `/api/admin/test-data`가 `[테스트]` 표시 직원과 연결된 행의 개수만 미리 보여 준다. 표시 안의 공백도 인식한다. `/api/admin/test-data/cleanup`은 현재 비밀번호·사유·변경되지 않은 계획 지문을 요구한다. 해당 직원의 출퇴근·근무·시급·하루 시급·수당을 한 트랜잭션으로 정리한다. 일반 직원·설정·기기·관리자 계정은 삭제하지 않는다. 확정 정산본이나 다른 직원 기록과 연결되어 있으면 정리를 거부한다. 삭제 작업의 감사 이력은 보존한다.

기기 안의 미전송 기록은 서버 정리와 별개다. 삭제된 테스트 직원의 오래된 미전송 기록도 자동으로 버리지 않는다. 정리 전에는 태블릿 연결·미전송 상태를 확인하고, 필요하면 기기에서 복구 파일을 보관한다. 서버 정리는 태블릿 토큰이나 실제 직원의 미전송 큐를 초기화하지 않는다.

직원을 찾을 수 없는 미전송 항목은 원래 UUID·시각을 유지한 채 기기에 남기고 5분 후 재시도한다. 같은 직원의 뒤 항목도 순서를 유지해 보류하지만 다른 직원 기록은 계속 전송한다. 이 항목만 남았으면 명단은 분당 한 번까지만 조회한다. 관리자 확인 안내와 복구 파일 보관 기능을 제공하며, 미전송 항목이 남은 동안 자동 업데이트는 보류한다.
