안드로이드 태블릿용 **필에듀 출퇴근**입니다.

1. 아래 **Assets → feeledu-attendance.apk**를 내려받아 설치하세요.
2. Android에서 요청하면 이번 설치에 사용할 Chrome의 ‘이 출처 허용’을 승인하세요.
3. 설치한 **필에듀 출퇴근**을 실행하세요.
4. PC 관리자 화면의 **설정 → 태블릿 연결**에서 받은 8자리 코드로 연결하세요.

관리자: https://feeledu-attendance.feeledu-pj-managing.workers.dev/admin

- 앱의 출퇴근 화면과 급여·관리 기능은 기존 Cloudflare 서버를 사용합니다. PC가 꺼져도 사용할 수 있습니다.
- 화면·계산 기능은 서버 배포로 업데이트됩니다. 앱 자체 변경 시 새 APK를 기존 앱 위에 설치하세요. 같은 서명을 유지하므로 앱을 삭제할 필요가 없습니다.
- 오프라인 입력은 기기에 보관했다가 재전송하며 관리자 확인이 필요합니다. 미전송 기록이 남아 있을 때 Chrome의 사이트 데이터나 앱 데이터를 지우지 마세요.
- Android 6 이상과 최신 Chrome이 필요합니다. Chrome과 같은 브라우저 프로필을 사용합니다. 앱·사이트 소유권 확인 후 주소창 없는 앱 화면으로 실행됩니다.
- APK의 서명 정보와 SHA-256 파일을 함께 제공합니다. 기존 직원·급여 DB와 관리자 비밀번호는 APK에 포함하지 않습니다.

공개 자동 검증을 통과해 배포한 설치 파일입니다. 실제 태블릿의 설치·출퇴근은 기기에서 확인해 주세요.
