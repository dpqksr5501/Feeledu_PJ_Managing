- 앱의 출퇴근 화면과 급여·관리 기능은 기존 Cloudflare 서버를 사용합니다. PC가 꺼져도 사용할 수 있습니다.
- 화면·계산 기능은 서버 배포로 업데이트됩니다. 앱 자체 변경 시 새 APK를 기존 앱 위에 설치하세요. 같은 서명을 유지하므로 앱을 삭제할 필요가 없습니다.

- 운영은 Android 10 이상과 최신 Chrome을 권장합니다. Chrome과 같은 브라우저 프로필을 사용합니다. 앱·사이트 소유권 확인 후 주소창 없는 앱 화면으로 실행됩니다. 최소 설치 OS는 Android 6이며 구형 브라우저의 전체 웹 기능까지 보장하지는 않습니다.
